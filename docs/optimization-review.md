# 项目审查与优化记录

审查基于 `d8fa051`，覆盖 Python 请求入口、双通道与原生协议、鉴权与控制台、
状态持久化、重试与续传、HTTP 客户端、图片处理、代理配置、Go 桥接代码、
部署文件和现有检查流程。以下改动集中于可复现的资源边界与错误处理问题。

## 已实施改进

| 问题 | 修复后的行为 | 主要文件 |
| --- | --- | --- |
| 管理写入缺少统一请求体上限，类型化接口可能在认证前解析大 JSON | 登录 256 KiB、其他管理写入 8 MiB；声明长度预检与实际分块计数同时生效 | `middleware.py` |
| Claude 声明长度超限返回 OpenAI 错误；手动 JSON 解析吞掉超限异常；原生错误格式不一致 | 所有拒绝路径共享协议映射，超限始终为 413；浏览器可读取预检的 CORS 响应 | `request_errors.py`、`main.py`、`routes/` |
| 非 ASCII 数字或数千位 Content-Length 可能在整数转换时抛异常 | 对 ASCII 十进制字符串按长度和值比较，无大整数转换 | `request_errors.py` |
| NaN/Infinity 参数虽被校验拒绝，但错误体再次序列化会变成 500；默认校验错误可能回显密码 | 保留字段位置与说明，移除 input/ctx，限制错误条数与字段长度；管理接口仍为 422 | `request_errors.py`、`main.py` |
| 模型清单完整下载，没有响应体和总时限预算 | 流式读取至多 1 MiB，每个来源总计至多 20 秒；失败保留旧缓存 | `model_loader.py`、`http_io.py` |
| 大批量 Key 探测创建与 Key 数量相同的任务和出站连接 | 最多 4 个 worker，单项失败隔离，返回次序不变；所有入口共享最多 4 路网络探测 | `express_key_probe.py` |
| 探测响应可任意增大，多出口尝试叠加等待 | 响应至多 256 KiB，单次网络探测总计至多 45 秒，继续支持代理故障切换 | `express_key_probe.py` |
| 保活会下载无用正文，自动重定向也会读取中间正文；环境代理与“直连”说明不一致 | GET 只读响应头，逐跳关闭，至多 5 次重定向、总计 30 秒；显式直连并支持自定义 CA | `keepalive.py` |
| 并发重启保活可能留下重复任务；旧配置的非法间隔可能影响启动 | 串行化启停与重启，非法配置只停用保活；保存时检查完整 HTTP(S) URL | `keepalive.py`、`settings_validation.py` |
| wait_for 在取消遭忽略时仍会无限等待，流式清理的五秒上限未真正生效 | 用 wait 限制等待任务退出的时间，迟到响应仍会被关闭并纳入后台任务管理 | `streaming.py` |
| 上游错误响应的脱敏覆盖少于日志，TURN/SSTP URI 和特殊 Bearer 字符可能泄漏 | 错误与日志共享脱敏规则，覆盖 URI 认证信息、查询密钥与完整 Bearer；正则保持有界前缀匹配 | `request_tracking.py`、`upstream_errors.py` |
| 冒烟脚本复用固定状态目录，并触发远程模型刷新 | 每次使用新的临时状态目录，屏蔽远程刷新，确保冒烟不依赖网络 | `scripts/smoke_final.py` |

## 验证边界与后续方向

- 本地仅提供 Python 3.12；Python 3.11 仍由现有 CI 矩阵验证。
- 当前环境没有 Go、Docker、sing-box 与桥接二进制，因此未执行 Go race
  检查、镜像构建或真实 TURN/SSTP 连接；本次没有修改 Go 或 Docker 代码。
- 没有真实上游凭据，未验证 Google 私有 Cookie 协议、真实模型输出或账号配额。
  没有修改模型清单、采样语义、重试次数或私有请求结构。
- 没有改动控制台前端资源，本次未运行 Playwright 浏览器回归。
- 新增资源预算已给出确定上限；未执行生产压测，不宣称固定延迟或吞吐提升。
- 对任意第三方任务，应用不能强制其协程配合取消；本次保证清理等待的时间边界，
  并在其最终返回时回收响应。响应自身的 `aclose()` 仍依赖底层传输的取消行为。

现有状态原子落盘、连接池、图片目的地址校验、续传容量控制与签名缓存已有
专门模块和回归覆盖；本次保留这些设计，避免改变核心行为造成兼容性回退。
