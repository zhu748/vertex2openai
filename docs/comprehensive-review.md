# 项目全面审查与优化（2026-10-24）

本轮基于 `8b7ce69`。审查涉及三种 API 入口、Express/Cookie 通道、重试与
续传、请求取消、客户端池、图片与 JSON 资源边界、凭证健康、控制台脚本、
状态落盘、Go 代理桥接、Docker 与 CI。下列修改均已在本地工作区实施。

## 发现与修复

| 优先级 | 发现 | 实施后的行为 |
| --- | --- | --- |
| P1 | Cookie 探测使用全量 POST 读取，未限制正文大小，多个代理可叠加等待 | 改用流式读取：最多 256 KiB、网络操作总计 45 秒，覆盖代理切换；鉴权拒绝直接关闭正文 |
| P1 | curl 的原始 `aclose()` 仅等待下载任务，超限或提前退出仍会继续下载并占用连接 | 适配器拥有流式响应清理，提前退出取消并等待该响应的生产任务；共享 session 保持可用 |
| P1 | Cookie 冷却只绑定账号 ID，替换凭证后继承旧冷却；旧请求能污染新凭证健康 | 健康绑定 Cookie/Project ID 摘要，生产路径传入凭证快照；更换、删除账号后清理旧状态，迟到成功/失败按身份隔离 |
| P1 | HTTP 200 的空正文、HTML、畸形结果可能被判为有效会话；多个错误仅保留最后一个 gRPC 状态 | 验证响应结构，读取全部错误；鉴权错误优先，暂时性上游错误归为无法判定，避免误清除健康状态 |
| P2 | Cookie 批量探测逐条串行执行 | 固定最多 4 个 worker，所有入口共享 4 路网络并发；结果顺序不变，逐项隔离异常 |
| P2 | 诊断器按网络块限制大小，大块内正常小事件会被误跳过；超限事件后的剩余内容可能绕过检查预算 | 按事件检查，按至多 64 KiB 片段扫描；保留跨块分隔符尾部，继续识别后续事件，每片段只压实一次缓冲 |
| P2 | 代理 `log_tail()` 读取整个日志再截取，`limit=0` 反而返回整个文件 | 按文件尾部最多 `4 × limit` 字节读取，正确保留 UTF-8 尾部；非正上限返回空串 |
| P2 | stdout 队列只限制数量，单条巨型异常仍能长期保留整份请求或图片正文 | 入队文本最多 16 Ki 字符，并保留截断提示与原长度 |
| P2 | Cookie 和 `cookie_authuser` 可保存为无法发送的请求头，导致之后每次调用失败 | 保存时拒绝非 ASCII、控制字符与换行；`cookie_authuser` 长度上限 128 |
| P2 | 登录限速先计算无界指数再截断，且最后不足一秒的等待被取整为零 | 指数计算前钳位，用向上取整保持完整等待窗口；429 返回 `Retry-After` |
| P2 | CI 测试任务继承 GHCR 包写权限 | workflow 默认只读，包写权限仅授予镜像发布任务 |
| P2 | 原有统一检查被未使用的 `config` 导入阻断 | 清理导入，恢复静态检查通过 |

探测实现从凭证路由移到 `app/cookie_probe.py`，路由保留原来的 URL、鉴权与
响应字段。探测的 `error` 表示网络/格式等原因无法判定，不应等同于确定的
凭证失效。批量任务的全程耗时取决于账号数量；45 秒是每项网络操作的期限，
不包含等待并发槽的时间。

## 验证边界与后续工作

- 未提供真实 Google Key/Cookie，未执行真实模型生成、配额或私有协议在线验证。
- 本环境没有 Go、Docker 或 sing-box，没有执行 Go race、镜像构建或真实
  TURN/SSTP 连接；本轮未修改 Go 代码、依赖版本或 Dockerfile。
- 控制台模板、JavaScript 和 CSS 未修改，未运行 Playwright UI 回归。
- Python 3.11 由现有 CI 矩阵验证；本地只运行 Python 3.12。
- 续传、统计、会话与缓冲仍为进程内状态；多副本共享与重启恢复需要明确的
  分布式存储方案，属于架构变更，本轮不引入新的基础设施。
- Cookie 传输依赖锁定版本的 curl 任务清理语义。升级依赖时应继续运行
  本地慢响应取消测试与池复用测试。

已有的连接池复用、状态原子落盘、SSRF 地址检查、请求体上限、生成并发
与续传预算均保留。本轮没有调整模型目录、默认采样、重试预算或生成协议。
